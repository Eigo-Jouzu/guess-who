# Guess Who?

Based on the popular board game of the same name.

Designed for iPads but is browser-based so will work on any modern computer.

Scan the QR code to play - a random character will be chosen. In pairs, take turns guessing the other person's character.

When one person thinks they know the other character's identity, they can press "I know!" to guess. If they're wrong, that character is permanently disabled. Guess wrong three times though, and the game is over!
